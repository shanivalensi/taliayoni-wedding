Structure

One index.html — scrolls top to bottom
Section 1 + Section 2 stack vertically on the page
Each section uses its background image at full width
No nav bar — pure immersive design

Language Switching

?lang=fr → French (default)
?lang=he → Hebrew + RTL layout
JS on load reads param, shows correct content block
Hebrew version mirrors layout right-to-left

Fonts (local files)

Slight — "Talia & Yoni" script
Montserrat Regular — French body text
Montserrat Bold — 2 specific headings
Hadasim CLM Regular — Hebrew body
Hadasim CLM Bold — Hebrew in French page
All loaded via @font-face from /fonts/

Colors & Style

All text: #8f5b3e
Backgrounds: #f7efe6 (cream)

Form fields → outlined, transparent background
